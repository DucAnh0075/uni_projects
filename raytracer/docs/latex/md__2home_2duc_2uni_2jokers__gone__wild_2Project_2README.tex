At startup, the program prompts for visualization toggles via the {\ttfamily \doxylink{structToggleSettings}{Toggle\+Settings}} helper in {\ttfamily \doxylink{toggles_8h_source}{toggles.\+h}}\+:


\begin{DoxyItemize}
\item show\+\_\+rays\+: Draw sample camera rays in red
\item show\+\_\+light\+\_\+rays\+: Draw sample light-\/to-\/pixel rays in white (from first point light)
\item show\+\_\+plane\+\_\+flow\+: Draw flow arrows on the plane showing the light’s tangent direction
\item plane\+\_\+flow\+\_\+stride\+: Arrow grid spacing (only asked if plane flow is enabled)
\end{DoxyItemize}

Leave inputs blank or answer {\ttfamily n} to disable; answer {\ttfamily y} to enable. The plane arrows are capped internally for performance.\hypertarget{md__2home_2duc_2uni_2jokers__gone__wild_2Project_2README_autotoc_md20}{}\doxysubsection{\texorpdfstring{Headless and CLI configuration}{Headless and CLI configuration}}\label{md__2home_2duc_2uni_2jokers__gone__wild_2Project_2README_autotoc_md20}

\begin{DoxyItemize}
\item {\ttfamily RT\+\_\+\+HEADLESS=1} – disable prompts
\item {\ttfamily RT\+\_\+\+SHOW\+\_\+\+RAYS=0\texorpdfstring{$\vert$}{|}1}
\item {\ttfamily RT\+\_\+\+SHOW\+\_\+\+LIGHT\+\_\+\+RAYS=0\texorpdfstring{$\vert$}{|}1}
