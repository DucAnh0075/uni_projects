Ray Tracer – Overview

This project is a simple C++ ray tracer using Eigen for math and OpenCV for image display and drawing. It supports spheres, axis-aligned cubes, and an infinite plane (half-space), with ambient + diffuse + specular lighting, hard shadows, and a few visualization overlays.

📚 Quick Documentation Access

make docs-serve # Generate docs and serve on localhost:8080
./generate_docs.sh serve # Alternative method

See the Documentation section for full details.

Geometry & Lighting

  • Objects: Sphere, Cube (AABB via slabs), HalfSpace (infinite plane)
  • Lights: Point and Directional
  • Shading: Ambient + Lambertian diffuse + Phong specular
  • Shadows: Hard shadows using shadow rays with occlusion checks

Screen

The screen is a world-space rectangle (in scene.h) that controls resolution and pixel mapping. The camera/observer is at the origin looking down −Z.

Build

Requirements:

  • C++17 compiler
  • OpenCV 4
  • Eigen 3

Typical build (Linux): use the provided Makefile or compile manually via pkg-config.

Using Makefile:

make # builds ./raytrace (release)
make run # builds then runs ./raytrace
make run-headless # run with prompts disabled (RT_HEADLESS=1)
make debug # debug build (-g -O0)
make clean # remove artifacts

Manual compile (if preferred): The binary will be named raytrace in the project folder.

Run & Toggles

At startup, the program prompts for visualization toggles via the ToggleSettings helper in toggles.h:

  • show_rays: Draw sample camera rays in red
  • show_light_rays: Draw sample light-to-pixel rays in white (from first point light)
  • show_plane_flow: Draw flow arrows on the plane showing the light’s tangent direction
  • plane_flow_stride: Arrow grid spacing (only asked if plane flow is enabled)

Leave inputs blank or answer n to disable; answer y to enable. The plane arrows are capped internally for performance.

Headless and CLI configuration

You can skip interactive prompts and configure toggles via environment variables or CLI flags.

Environment variables:

  • RT_HEADLESS=1 – disable prompts
  • RT_SHOW_RAYS=0|1
  • RT_SHOW_LIGHT_RAYS=0|1
  • RT_SHOW_PLANE_FLOW=0|1
  • RT_PLANE_FLOW_STRIDE=<16..512>

CLI flags (override defaults; prompts are still shown unless --headless is set):

  • --headless or --no-prompt
  • --show-rays[=0|1]
  • --show-light-rays[=0|1]
  • --show-plane-flow[=0|1]
  • --plane-flow-stride <N> or --plane-flow-stride=N

Documentation

This project includes comprehensive API documentation generated with Doxygen. The documentation covers all classes, methods, and data structures with detailed descriptions and usage examples.

📚 Viewing Documentation

The easiest way to generate and view the documentation:

# Generate documentation
make docs
# Generate and serve on localhost:8080
make docs-serve
# Alternative: use the documentation script
./generate_docs.sh serve

Then open http://localhost:8080 in your browser.

🔧 Documentation Generation Options

Method 1: Using Makefile (Recommended)

make docs # Generate documentation
make docs-clean # Clean documentation files
make docs-serve # Generate and serve on localhost:8080
make docs-install # Install Doxygen if needed

Method 2: Using Documentation Script

./generate_docs.sh # Generate documentation
./generate_docs.sh serve # Generate and serve documentation
./generate_docs.sh open # Generate and open in browser
./generate_docs.sh clean # Clean documentation files
./generate_docs.sh install # Install Doxygen dependencies

Method 3: Manual Doxygen

# Install Doxygen first
sudo apt install doxygen graphviz # Ubuntu/Debian
# or: sudo yum install doxygen graphviz # CentOS/RHEL
# or: brew install doxygen graphviz # macOS
# Generate documentation
doxygen Doxyfile
# View documentation
open docs/html/index.html
